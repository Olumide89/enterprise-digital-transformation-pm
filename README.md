# Enterprise Digital Transformation Project

**Simulated project-management case study | BerlinRetail GmbH | €1.2 million | 12 months | 15-person team**

This repository presents an end-to-end predictive project-management simulation for a fictional Berlin-based retailer replacing fragmented spreadsheets and legacy workflows with a cloud-based ERP and workflow platform.

## Business problem

BerlinRetail GmbH experiences fragmented data, manual approvals, inconsistent reporting and limited visibility across departments. The project aims to implement an integrated cloud ERP and workflow platform to improve operational efficiency, data quality and decision-making.

## Simulated role

Project Manager responsible for initiation, planning, stakeholder alignment, schedule and cost control, change management, reporting and project closure.

## Methodology

Predictive/waterfall delivery with formal stage gates, baseline management, change control and structured governance.

## Planned artifacts

- Business case
- Project charter
- Stakeholder register
- Scope statement
- Work breakdown structure (WBS)
- Milestone plan and dependency network
- Baseline Gantt schedule
- Cost baseline
- RAID log
- Change request log
- Acceptance criteria
- Lessons learned and closure report

## Decision-making simulation

A six-week vendor delay is introduced during delivery. The case study will assess the impact on the critical path, schedule and budget; compare recovery options; document a steering-committee recommendation; and produce a revised baseline.
